# Student Performance Predictor

## Project Overview
Student Performance Predictor is a Machine Learning project designed to analyze student-related data and predict student performance using Python.




## 🚀 Live Demo

Try the deployed Student Exam Performance Predictor:

https://student-performance-predictor12.streamlit.app/

## 📊 Model Performance

- Algorithm: Selected regression model
- R² Score: 0.8804
- Target Variable: Maths Score

## 🛠️ Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit
- CatBoost and XGBoost
